API reference

15 resource groups, one SDK.

Every method below is available on the Nomba (sync) or AsyncNomba (async) instance under the resource group shown in each heading. The signatures shown are the synchronous variants; the async variants are identical except they return Futures and require .await. Field names and paths come straight from Nomba's OpenAPI spec.
